# **Times Trivia Challenge - Gamified News Delivery**

**Project:** Times Trivia Challenge  
**Platform:** [https://timestriviachallenge.netlify.app/](https://timestriviachallenge.netlify.app/)  
**Role:** Software Developer Engineer Intern  
**Organization:** Times of India  

## **Overview**

The **Times Trivia Challenge** is a gamified platform designed to engage users with news content through interactive games. Created during an internship at **Times of India**, this project aims to make news delivery more engaging by incorporating various fun and educational games, including **Word Matching**, **Quiz**,**Spot the difference** and more. The website encourages users to interact with news stories while enjoying a range of mind-stimulating activities, enhancing both learning and entertainment.

## **Features**

- **Gamified News Delivery:** Engage with the latest news through interactive games that make staying informed fun.
- **Word Matching Game:** Match news-related words with their correct meanings or partners to improve vocabulary and comprehension.
- **Sudoku:** Solve daily Sudoku puzzles based on current news, helping users improve problem-solving skills while staying updated.
- **Daily Challenges:** New challenges are available daily, keeping the experience fresh and interesting.
- **Responsive Design:** Fully responsive design ensuring a smooth experience across various devices, including desktop, tablet, and mobile.

## **Technologies Used**

- **Frontend:**
  - HTML5, CSS3, JavaScript
  - React.js for dynamic and interactive UI components
  - Tailwind for responsive design

- **Deployment:**
  - Netlify for hosting and deployment

## **Setup and Installation**

1. **Clone the Repository:**

```bash
git clone https://github.com/bhavyasingh9822/times-trivia-challenge.git
```

2. **Navigate to the Project Directory:**

```bash
cd times-trivia-challenge
```


This will start the local development server at `http://localhost:3000` where you can access the website.
